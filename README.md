## about

**clckr.** is a customizable clicker game for android.

build your click count, buy upgrades, customize your button,
complete daily challenges and more.

## features

- customizable clicker
-  autoclickers
-  click multipliers
-  custom colors and skins
-  ranked mode
-  daily challenges
-  extensive settings
